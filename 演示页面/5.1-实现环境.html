5.1 实现环境

管理员 | 2026-05-20

🖥️ 开发环境

操作系统 Windows 10 / Windows 11
开发工具 微信开发者工具、IDEA、VS Code
开发语言 Java
后端框架 SpringBoot
前端技术 WXML、WXSS、JavaScript
数据库 MySQL 8.0
编译环境 JDK 1.8

☁️ 运行环境

服务器 CentOS / Windows Server
运行容器 Tomcat
客户端 微信客户端
适配设备 安卓 / iOS 全机型
网络 4G / 5G / WiFi
硬件要求 普通智能手机

📦 技术栈一览

后端Java + SpringBoot + MyBatis
前端微信小程序原生（WXML / WXSS / JS）
数据库MySQL 8.0 + MongoDB云数据库
架构B/S架构 + 前后端分离

5.10 系统接口管理

开发者 | API v1.0

🔐 认证模块

POST/api/user/login
用户登录接口，支持老人/家属/管理员三种身份登录
参数类型必填说明
usernameString是登录账号
passwordString是登录密码
roleInteger是身份 1-老人 2-家属 3-管理员
{ "code": 200, "msg": "登录成功", "data": { "token": "eyJhbGciOiJIUzI1NiIs...", "userInfo": {} } }

📊 健康数据模块

POST/api/health/upload
上传老人健康数据（心率/血压/血糖/体温）
{ "code": 200, "msg": "上传成功", "data": { "recordId": 10234 } }
GET/api/health/stats?range=week
获取健康数据统计概览（近7天/30天/90天）
GET/api/health/list?elderId=1001&page=1&size=20
分页查询健康数据记录

👨‍👩‍👧 家属监护模块

POST/api/family/bind
家属发起绑定老人申请
GET/api/family/monitor?bindId=2001
获取实时监护数据（心率/血压/位置/步数）

🚨 预警与推送模块

POST/api/alert/sos
触发一键紧急求助
GET/api/push/logs?page=1&size=20
查询消息推送记录
📄 Swagger 配置 - Knife4jConfig.java
@Configuration
@EnableKnife4j
public class Knife4jConfig {

    @Bean
    public Docket defaultApi() {
        return new Docket(DocumentationType.SWAGGER_2)
            .apiInfo(new ApiInfoBuilder()
                .title("老人安全健康监测系统 API")
                .description("基于微信小程序的老人安全健康监测")
                .version("v1.0")
                .build())
            .select()
            .apis(RequestHandlerSelectors
                .basePackage("com.elder.controller"))
            .paths(PathSelectors.any())
            .build()
            .securitySchemes(List.of(
                new ApiKey("Authorization",
                    "token", "header")
            ));
    }
}

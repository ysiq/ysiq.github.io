# 前端技术

前端技术开发的是用户**看得见、摸得着**的部分，即应用程序的界面和交互。无论是手机 App、电脑软件还是网页，你看到的按钮、输入框、动画、图表，都是前端技术的产物。

前端技术能做什么：

- **网站与 Web 应用**：企业官网、电商平台、后台管理系统
- **移动端**：微信小程序、H5 页面、跨平台 App（React Native / UniApp）
- **桌面软件**：用 Electron 构建的 VS Code、Slack、Discord 等商业软件
- **数据可视化**：ECharts 图表、Three.js 3D 场景、大屏驾驶舱
- **硬件交互**：串口通信、USB/蓝牙控制、物联网配置工具
- **实时通信**：WebSocket 聊天、协同编辑、在线游戏
- **音视频处理**：WebRTC 视频通话、在线直播、Canvas/WebGL 图形渲染

前端开发的核心是 **HTML、CSS、JavaScript 三件套**，它们共同构成了网页的基础：

- **HTML** 定义页面有什么（结构）
- **CSS** 定义页面长什么样（样式）
- **JavaScript** 定义页面能做什么（交互）

在此基础上，衍生出框架、库、工具链等丰富生态。本文从基础到实践，系统梳理前端技术栈。

## 一、基础三件套

### 1.1 HTML

**超文本标记语言（HyperText Markup Language）**

**定位**：**结构化文档描述语言**，用于定义页面的**语义结构与内容载体**。

**本质**：标记型、声明式、无逻辑、无计算能力。

**核心职责**：

1. 定义页面包含哪些**元素节点**（标签）。
2. 为内容赋予**语义**（标题、段落、按钮、输入框、列表、容器等）。
3. 提供元素**属性**（id、class、src、type 等）作为标识与配置。
4. 构建**DOM 树结构**（Document Object Model），为后续渲染与操作提供结构基础。

**语法特征**：

- 由`<标签>`构成，标签可嵌套、可自闭和。

- 不支持变量、条件、循环、函数。

- 仅描述 "**有什么**"，不描述 "**什么样**" 和 "**做什么**"。

### 1.2 CSS

层叠样式表（Cascading Style Sheets）

  **定位**：**表现层描述语言**，用于定义 HTML 元素的**视觉呈现与布局规则**。

  **本质**：样式型、声明式、无计算逻辑（现代 CSS 具备有限表达式）。

  **核心职责**：

  1. 定义元素**布局模型**（盒模型、Flex、Grid、定位、浮动）。
  2. 定义**视觉样式**（颜色、尺寸、字体、边距、背景、边框、阴影等）。
  3. 定义**状态与响应式**（hover、active、媒体查询、动画过渡）。
  4. 通过**选择器**匹配元素，遵循**层叠、优先级、继承**规则应用样式。

  **语法特征**：

  - `选择器 { 属性: 值; }`
  - 不直接操作数据，不执行业务逻辑。
  - 仅描述 "**长什么样**"，不描述 "**做什么**"。

### 1.3 JavaScript（JS）

动态脚本语言

**定位**：**行为层与逻辑层编程语言**，实现交互、数据处理、系统调用。

**本质**：解释型、动态类型、基于原型、支持函数式 / 面向对象。

**核心职责**：

1. 操作 DOM：增删改查元素、修改内容、绑定事件。
2. 实现**交互逻辑**：点击、输入、表单验证、状态管理。
3. 处理**数据与计算**：变量、条件、循环、函数、异步（Promise/async）。
4. 调用**系统 / 平台能力**：网络请求、文件读写、USB / 串口 / 蓝牙（Node.js/Electron 环境）。
5. 驱动应用生命周期与状态流转。

**语法特征**：

- 支持完整编程范式：变量、表达式、控制流、函数、对象、模块。
- 可与 HTML/CSS 完全分离，也可内联。
- 负责 "**做什么、怎么交互、如何通讯**"。

**运行环境**：

- 浏览器
- Node.js
- Electron
- 小程序、APP 引擎等

## 二、主流前端框架

前端框架帮助开发者高效构建用户界面，提供组件化、状态管理、路由等能力。以下是当前主流的四大前端框架：

### 2.1 React

**定义**：由 **Facebook (Meta)** 开发的声明式、组件化 UI 库。

**定位**：**用于构建用户界面的 JavaScript 库**，专注于视图层，生态由社区补充。

**核心特性**：
- **组件化**：一切皆组件，组件可组合、可复用
- **JSX**：在 JavaScript 中编写类似 HTML 的模板语法
- **虚拟 DOM**：通过 Diff 算法高效更新真实 DOM
- **单向数据流**：数据从父组件流向子组件，易于追踪
- **Hooks**：`useState`、`useEffect`、`useContext` 等函数式状态管理

**适用场景**：大型单页应用（SPA）、跨平台开发（React Native）、移动端 Web

**版本演进**：React 19 已稳定发布，支持 Server Components、Actions 等新特性

### 2.2 Vue.js

**定义**：由 **尤雨溪（Evan You）** 开发的渐进式前端框架。

**定位**：**渐进式框架**，可逐步增强，从轻量视图层到全家桶均可按需选用。

**核心特性**：
- **响应式系统**：基于 Proxy 的数据绑定，自动追踪依赖并更新视图
- **组合式 API**：`ref`、`reactive`、`computed`、`watch` 等灵活组合逻辑
- **单文件组件（SFC）**：`.vue` 文件中同时编写模板、脚本、样式
- **指令系统**：`v-for`、`v-if`、`v-model` 等直观模板语法
- **生态一体**：Vue Router（路由）、Pinia（状态管理）、Vite（构建工具）

**适用场景**：中小型项目快速开发、大型企业应用、渐进式迁移

**版本演进**：Vue 3.x 已成为默认版本，Vue 2 已于 2024 年停止维护

```vue
<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>

<template>
  <button @click="count++">点击 {{ count }} 次</button>
</template>
```

### 2.3 Angular

**定义**：由 **Google** 开发的企业级前端框架。

**定位**：**完整的前端解决方案**，提供从开发到测试的一整套工具链。

**核心特性**：
- **TypeScript 原生**：Angular 从头基于 TypeScript 构建，类型安全
- **模块化架构**：NgModule 组织代码，依赖注入管理服务
- **双向数据绑定**：`[(ngModel)]` 视图与模型自动同步
- **RxJS 响应式编程**：基于 Observable 处理异步和数据流
- **官方工具链**：CLI 脚手架、路由、表单验证、HTTP 客户端、测试工具

**适用场景**：大型企业级应用、复杂业务系统、团队协作项目

**版本演进**：Angular v18+ 采用新控制流语法，全面拥抱 standalone 组件（不再强制 NgModule）

### 2.4 Svelte

**定义**：由 **Rich Harris** 创建的编译器型前端框架。

**定位**：**编译时框架**，将声明式代码编译为极致精简的纯 JavaScript。

**核心特性**：
- **无虚拟 DOM**：编译时直接操作 DOM，体积小、性能高
- **响应式声明**：`let count = 0; $: double = count * 2` 简洁直观
- **极简语法**：无需 JSX 或复杂 API，贴近原生 Web 标准
- **内置动画**：`transition`、`animate` 指令轻松实现动画效果
- **编译产物**：打包后代码量极小，适合低端设备和性能敏感场景

**适用场景**：高性能交互页面、小型工具、嵌入式 Web、渐进增强

**版本演进**：Svelte 5 引入 Runes（`$state`、`$derived`、`$effect`）统一响应式机制

### 2.5 框架对比

| 框架 | 类型 | 响应式 | 虚拟DOM | 学习曲线 | 适用规模 | 生态 |
|------|------|--------|---------|----------|----------|------|
| React | UI库 | Hooks | ✅ | 中等 | 大型 | 极庞大 |
| Vue | 渐进式框架 | Proxy | ✅ | 平缓 | 中大型 | 完善 |
| Angular | 全功能框架 | Zone.js | ❌ | 陡峭 | 大型企业 | 官方全栈 |
| Svelte | 编译型框架 | 编译期 | ❌ | 低 | 中小型 | 成长中 |

### 3.6 3D 图形（Three.js）

**定义**：**JavaScript 3D 图形库**，用于在浏览器中创建和展示 3D 图形。

**定位**：**Web 3D 图形渲染引擎**，让网页拥有 3D 可视化能力。

**核心功能**：

- 场景（Scene）、相机（Camera）、渲染器（Renderer）三大基础组件
- 支持多种几何体：立方体、球体、平面、自定义模型等
- 材质与纹理：颜色、贴图、光照、阴影效果
- 动画系统：帧循环、过渡动画、骨骼动画
- 交互支持：鼠标事件、键盘控制、碰撞检测
- 后处理效果：泛光、景深、运动模糊等

**语法特征**：

```javascript
// 创建场景
const scene = new THREE.Scene();

// 创建相机
const camera = new THREE.PerspectiveCamera(75, width/height, 0.1, 1000);

// 创建渲染器
const renderer = new THREE.WebGLRenderer();
renderer.setSize(width, height);
document.body.appendChild(renderer.domElement);

// 创建几何体
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 动画循环
function animate() {
    requestAnimationFrame(animate);
    cube.rotation.x += 0.01;
    cube.rotation.y += 0.01;
    renderer.render(scene, camera);
}
animate();
```

- 数据可视化：大数据图表、地理信息展示
- 游戏开发：网页3D游戏、虚拟现实
- 产品展示：3D产品浏览、在线展厅
- 数字孪生：工业仿真、建筑可视化
- 教育培训：化学分子结构、物理模拟

## 四、运行环境

JavaScript 的运行环境决定了它能调用哪些系统 API。

### 4.1 浏览器

- 最原始的 JS 运行环境
- 提供 DOM / BOM / Web API（Canvas、WebGL、WebSocket 等）
- 沙箱隔离，不能直接访问文件系统或操作系统

### 4.2 Node.js（服务端运行时）

**定义**：**基于 V8 引擎的 JavaScript 运行时环境（Runtime）**。

**定位**：**让 JS 可以脱离浏览器运行在操作系统上**。

**核心提供**：

- 文件系统 fs
- 网络 net / http
- 进程 process
- 子进程 child_process
- 串口、USB、蓝牙调用能力
- 模块系统

本质：运行环境 + 系统 API 集合。

### 4.3 Electron（桌面端框架）

**定义**：由 GitHub 开发的开源框架，允许使用 **Web 技术栈（HTML + CSS + JavaScript）** 构建 **跨平台桌面应用程序**。

**核心组成**：

1. **Chromium**：负责渲染界面（浏览器内核）
2. **Node.js**：负责操作系统级 API 调用

**两种进程**：

| 进程 | 数量 | 职责 | 能力 |
|------|------|------|------|
| 主进程 | 唯一 | 建窗口、菜单、托盘、自动更新 | Node.js 全部 API |
| 渲染进程 | 每个窗口一个 | 显示界面 | HTML/CSS/JS，默认不可调 Node.js |

**主进程 ↔ 渲染进程** 通过 **IPC（进程间通信）** 传递数据。

**能力概览**：

- ✅ 桌面窗口管理（全屏、置顶、无边框）
- ✅ 系统原生功能（托盘、通知、快捷键、开机自启）
- ✅ 操作系统底层（文件、进程、串口、USB、蓝牙、HID）
- ✅ 任何前端框架（Vue / React / Angular）
- ✅ 一次开发，Windows / macOS / Linux 三平台发布

**最简项目结构**：

```
your-app/
├── package.json
├── main.js
└── index.html
```

**运行**：

```bash
npm install electron
npx electron .
```

**打包成 exe**：

```bash
npm install @electron/packager -D
npx electron-packager . myapp --platform=win32
```

**优点**：

- 开发效率极高
- 跨平台
- 界面美观现代化
- 可直接调用硬件（USB / 蓝牙 / 串口）
- 生态极其强大

**缺点**：

- 应用体积较大（至少 50MB+）
- 内存占用高于原生软件
- 极高性能场景不如 C++
